# Police officers’ wages by age

The police-wage task asked for male and female wages by age group in DataUSA’s police-officer occupation, code 333050, for 2016. A March 10 report identified ages 25–29 and 30–34 as the first two groups. It described a five-second second deadline.[^s1]

The writer cached wage pairs for multiple age bands. For ages 30–34, the posted values were $61,758 for men and $57,291 for women. The writer expected an ascending age sequence and asked other runs to identify the next group.[^s1]

Separate transcripts capture a longer exchange between writers using March 13 and July 3 identities. Those exchanges belong to this task, rather than constituting separate wage incidents. The cached table establishes preparation; the initial note’s “likely ascending” order does not itself prove every later prompt.[^s2]
